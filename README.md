# OP Mob Drops

Fabric mod for Minecraft Java **1.21.11**. When a player kills any living mob (including cows, chickens, zombies, etc.), it has a 35% chance to drop one randomly chosen powerful reward. This source currently uses fixed chance and does not provide a configuration UI.

## Get the JAR

Go to **Actions → Build Fabric mod → latest successful run → Artifacts → op-mob-drops-fabric-1.21.11**. Download and extract the artifact ZIP; place the contained `op-mob-drops-1.0.0.jar` in your Fabric profile's mods folder. Also install Fabric API. Do not install the source ZIP.

## Build locally

Requires Java 25 and Gradle 9.2.1: `gradle build`.

**Note:** This source has not been verified against a completed GitHub Actions build yet. Check Actions for compilation results before installing.
