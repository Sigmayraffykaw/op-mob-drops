# OP Mob Drops v1.1.0

Fabric mod for Minecraft Java **1.21.11**. Every player-killed living mob, including passive animals, drops **one guaranteed extra reward** selected randomly from 30 powerful item options. These are additional drops alongside vanilla loot.

Rewards: netherite sword, pickaxe, chestplate, helmet, leggings, boots, axe, shovel, hoe; Elytra; 4 enchanted golden apples; 32 diamonds; 64 emeralds; 4 netherite ingots; 3 totems; trident; mace; 2 netherite blocks; 8 diamond blocks; 8 emerald blocks; nether star; beacon; 2 shulker boxes; 8 end crystals; 16 golden apples; 64 experience bottles; heavy core; 16 breeze rods; 16 dragon's breath; 16 ancient debris.

**Note:** Equipment is not enchanted in this version. This mod is extremely overpowered and will affect survival balance.

## Install

Open **Actions → Build Fabric mod → latest successful run → Artifacts → op-mob-drops-fabric-1.21.11-v1.1.0**. Download and extract the ZIP, then place `op-mob-drops-1.1.0.jar` in the Fabric 1.21.11 profile's `mods` folder. **Remove the old 1.0.0 JAR** first. Install Fabric API too.

The mod is built on GitHub Actions. Test in a disposable world before Hardcore.
